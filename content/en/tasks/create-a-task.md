1. **[Open](/basics/open-an-application-in-the-launcher) Tasks**.
2. Tap the list you want to assign the task to > **+** at the bottom of the list > enter the task name in the **Task name...** field.
3. Press **Enter** to save the task and start another, or tap elsewhere when you're done.

If you add a task while viewing **List all tasks**, it goes in the **Unfiled** list ([**learn how**](/tasks/use-the-unfiled-list)).

To use Just Type to create a task: In Card view, tap **Just type...** > start typing the task. Under **Quick Actions**, tap **New Task** (tap **More...** if you don't see it). Tasks opens the details of a new task in **Unfiled**, with the text you entered as the task name.

See Also [**Create a task list**](/tasks/create-a-task-list)
