1. **[Open](/basics/open-an-application-in-the-launcher) Tasks**.
2. Do one of the following:
   - To find a task: Tap a list, or **List all tasks** to look in every list. Enter part of the task name in **Search tasks**.
   - To find a list: Enter part of the list name in **Search lists**.

The list shows only the matches as you type, with the matching text marked in tasks. Clear the search box to see everything again.

Search looks at task names only, not notes. If you've hidden completed tasks, they stay hidden while you search ([**learn how**](/tasks/check-off-a-task)).
