This isn't in every copy of Documents. If you don't see the pencil button, your copy can't edit this kind of file. Workbooks are different: see [Edit a workbook](/documents/edit-a-workbook).

Documents never changes the original. You save your changes as a new file beside it.

1. Open a text document, a presentation, or a plain text or Markdown file.
2. Tap the pencil button at the bottom of the screen.
3. Edit it:
   - **OpenDocument text and presentations:** Tap a paragraph, change it, and tap **Done**.
   - **Word:** Type in the page. The bar has undo, redo, bold, italic, underline, bullets and numbering. The Word editor can take a while to load the first time.
   - **Plain text and Markdown:** Change the text in the box.
4. Tap **Save a Copy**, check the name, and confirm.

In presentations you can change the text on slides, but not move boxes or add slides.
