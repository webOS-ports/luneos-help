1. **[Open](/basics/open-an-application-in-the-launcher) Messaging** > **[Menu](/basics/open-the-application-menu)** (upper left) > **Preferences & Accounts** > **Add An Account** > tap **Teams**.
2. Under **EMAIL ADDRESS**, enter your Microsoft email address. If you like, enter a **DISPLAY NAME**.
3. Tap **Sign In** and sign in to Microsoft in the window that opens. You return to the account when you're done.

If that doesn't work, tap **Use device code instead**. Teams then sends a one-time code to you in Messaging, with the web address to enter it at.
