1. To create a new event, tap **New event**. To change an event you already created, tap the event name > **Edit**.
2. Under **Alerts**, tap the current setting > tap the new setting for the alarm.

   The default is 15 minutes before the start of the event. You can change the default ([**learn how**](/calendar/customize-calendar)).
3. Tap **Done**.
