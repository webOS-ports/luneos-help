1. **[Open](/basics/open-an-application-in-the-launcher) Calendar**.
2. Tap the event name > **Delete** > **Delete**. If this event is one of a series of repeating events, tap **Delete This Event Only** or **Delete The Whole Series**.

If you delete an event that is assigned to an online account, the event is deleted in the online account also.
