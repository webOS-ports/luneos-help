1. **[Open](/basics/open-an-application-in-the-launcher) Calendar** > **[Menu](/basics/open-the-application-menu)** > **Preferences & Accounts**.
2. Set the following options:

   **Accounts:** For all calendar accounts, tap an account to change login settings or remove the account. Change login settings only if you have changed this information for the calendar account online. The information you enter here must match the information in the online account.

   **Add an Account:** Tap the account type > enter the information for your online calendar account ([**learn how**](/calendar/set-up-an-online-account-in-calendar)).

   **Sync now:** Tap to manually sync your calendar accounts.

   **Default Launch View:** Select the view Calendar opens in: **Last Used**, **Day**, **Day Agenda**, **Week**, **Week Agenda**, or **Month**.

   **Default Calendar:** New events are assigned to this calendar. Tap to change it.

   **First Day of Week:** Select the day that appears as the start of the week in Week view and Month view.

   **Default Event Duration:** Select **30 minutes**, **1 hour**, or **2 hours**.

   **Default Event Reminder:** Tap the interval for a notification to appear, for timed events and for all-day events. Reminders you set for individual events override the default setting.

   **Event Reminders:** Select how a calendar notification alerts you ([**learn how**](/calendar/customize-event-notification-sounds)).

   **Calendar Colors:** Set the color for events in each calendar.
3. Tap **Done**.
