1. **[Open](/basics/open-an-application-in-the-launcher) Preware 2**.
2. To refresh the list of available packages: **[Menu](/basics/open-the-application-menu)** (upper left) > **Update Feeds**. By default, Preware 2 also does this every time it starts. You can change this in **Preferences** in the same menu.
3. Tap **Package Updates**.
4. Do one of the following:
   - To update one package: Tap the package > **Update**.
   - To update all packages: Tap **Update All**.
