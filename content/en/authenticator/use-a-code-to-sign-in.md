1. **[Open](/basics/open-an-application-in-the-launcher) Authenticator**.
2. Tap the account. This copies its code.
3. Go to the site or app that's asking for the code and paste it ([**learn how**](/basics/cut-copy-and-paste-information)).

The ring next to the code shows how long it has left, and turns red near the end. When time runs out, a new code appears. If the ring is nearly closed, wait for the new code so you have time to enter it.

Some accounts use counter-based codes, which don't change by themselves. These show **Tap for a code**. Tap **Show code** to make a code, and **Next code** to make a new one.
